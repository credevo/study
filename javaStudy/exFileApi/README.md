## Java 파일 API 쉬운 예제 10개

`src` 폴더에서 원하는 `Example01...Example10` 파일을 열고 `main` 메서드를 실행하세요.

실행하면서 생성되는 연습 파일은 프로젝트의 `practice-files` 폴더에 저장됩니다.

1. `Example01CreateFile` - 폴더와 빈 파일 만들기
2. `Example02WriteText` - 텍스트 쓰기
3. `Example03ReadText` - 텍스트 읽기
4. `Example04AppendText` - 내용 추가하기
5. `Example05FileInfo` - 파일 정보 확인하기
6. `Example06ListFiles` - 폴더 목록 보기
7. `Example07CopyFile` - 파일 복사하기
8. `Example08MoveFile` - 파일 이름 바꾸기
9. `Example09DeleteFile` - 파일 삭제하기
10. `Example10ReadLines` - 한 줄씩 읽기
