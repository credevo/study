# 공통 오답·실수 노트

## Maven 라이브러리의 위치가 항상 프로젝트 `WEB-INF/lib`라는 오해

### 잘못된 이해

Maven 프로젝트의 라이브러리와 수동 프로젝트의 라이브러리가 항상 같은 위치에 있다고 생각하기 쉽다.

### 올바른 이해

Maven의 원본 JAR는 보통 `.m2\repository`에 저장된다. `WEB-INF/lib`는 WAR를 패키징할 때 런타임 의존성이 모이는 배포 위치다. 수동 프로젝트는 이 배포 위치에 JAR를 직접 보관한다.

### 예방 방법

라이브러리의 원본 저장 위치, 컴파일 classpath, WAR 내부 배포 위치를 구분해서 확인한다.

프로젝트별 교정 기록: [mvc3_2 오답 노트](../mvc3_2/docs/MISTAKES.md)
