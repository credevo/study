# mvc3_2 오답·실수 노트

## Maven 프로젝트 라이브러리 위치에 대한 이해 교정

### 잘못된 이해

Maven 프로젝트의 라이브러리와 수동 JAR 프로젝트의 라이브러리가 같은 위치에 있다고 이해할 수 있다.

### 수정된 이해

Maven은 원본 JAR를 보통 `.m2\repository`에 저장하고, WAR를 만들 때 필요한 런타임 JAR를 `WEB-INF/lib`에 포함한다. 수동 프로젝트는 필요한 런타임 JAR와 전이 의존성을 직접 `WEB-INF/lib`에 구성한다.

### 이 프로젝트에 적용할 기준

수동 JAR 프로젝트로 전환할 때에는 `target/mvc3_2.war`의 `WEB-INF/lib` 구성을 기준으로 하되, Tomcat 제공 라이브러리인 Servlet API는 넣지 않는다.

## 문서 배치 개선

### 개선 전

초기 설정 노트를 프로젝트 루트의 `SETUP_NOTES.md` 한 파일에 작성했다.

### 개선 후

공통 학습 지식은 `study/docs/`, 이 프로젝트의 실제 설정·이력·이슈는 `mvc3_2/docs/`에 나누어 기록한다. 공통성과 프로젝트 영향이 모두 있는 사건은 두 위치에 각각의 범위에 맞게 기록한다.
